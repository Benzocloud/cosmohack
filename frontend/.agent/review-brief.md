# Review brief — frontend FE-0 / FE-1 / FE-3

Бриф для агента, принимающего работу frontend на этапах FE-0 (каркас), FE-1 (API-слой и моки), FE-3 (карта, контуры, рисование, добавление). Документ самодостаточен: контекст команды не нужен.

## Что ревьюится

- Ветка: **`frontend/fe-0`** (дифф против `main`). Рабочая зона — только `frontend/`.
- Хронология: FE-0 — каркас и дизайн-система; FE-1 — API-слой, адаптеры, моки; FE-3 — карта/контуры/рисование/добавление. FE-2 (карточка участка, полный список), FE-4 (график NDVI), FE-5 (события) — следующие этапы, их в этой ветке нет.

## Как проверить сборку и тесты

```bash
cd frontend
npm ci
npm run typecheck   # tsc, два tsconfig
npm run lint        # biome check
npm run test        # vitest, 61 тест (адаптеры, lib/geo, lib/series, хуки на msw, роутинг)
npm run build       # dist/ без сети к бэку и без env
```

## Как посмотреть вживую

```bash
cd frontend && npm run dev   # http://localhost:5173
```

Сквозной сценарий для проверки руками (mock): «Найти контуры» → клик по пунктирному контуру → «Добавить участок» → «Добавить и проанализировать» → участок в списке со статусом «Выполняется · <стадия>» → через ~6 с перекрашивается по verdict. Рисование: «Нарисовать участок» (иконка пера) → 3 клика/тапа → «Отменить точку»/«Завершить» → форма → «Только сохранить». На мобиле (390, touch): вкладка «Карта», то же самое тапами.

## Известные особенности реализации (не баги)

- `terraform`-рисование: terra-draw 1.33 — публичного `finish()` нет, «Завершить» диспатчит keyup Enter на элементы карты с фолбэком; `undo()` в режиме рисования не работает — «Отменить точку» пересоздаёт черновик синтетическими кликами; клик в 40 px от вершины снапится режимом.
- Моки: POST `/api/areas` эхом сохраняет источник; live-задача при завершении ставит `last_result` даже новому участку; все фикстуры помечены `_synthetic: true`.
- Строка атрибуции длинная (стиль Positron несёт свою + кастомная «Контуры: © OSM») — требование «всегда видна» выполнено.
- `npm` окружения блокирует postinstall-скрипты (esbuild/biome/msw) — бинарники идут через optionalDependencies, на сборку/линт не влияет.

## Границы ревью

- Backend ещё не готов: сеть никуда не ходит (кроме тайлов карты и MSW-перехвата).
- Не ревьюить как законченный продукт: FE-2/FE-4/FE-5 добавят карточку, график и события; текущие заглушки зон помечены `SCAFFOLD`.
- Вопросы к бэкенду фиксируются в `ui-spec.md` §8.2 (только добавление строк).
