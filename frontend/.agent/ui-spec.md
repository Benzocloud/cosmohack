# UI-spec — интерфейс мониторинга вегетации

Статус: **черновик, заполняется поэтапно**. Разделы с пометкой `TBD` заполняются владельцем frontend после указанного этапа.
Агент: в этот файл можно добавлять строки в раздел 8.2 и 8.3; удалять или переписывать чужие пункты нельзя.
Источники: `.agent/design-brief.md`, `frontend/.agent/corrections.md`, `frontend/.agent/fable5.1.md`.

## 1. Макет
- Выбран вариант: **A** — список слева, карта в центре, карточка справа, график под картой (design-brief §2, fable5.1 §6.1).
- Обоснование: однозначно раскладывается в мобильные вкладки «Участки / Карта / Анализ»; график получает полную ширину карты.
- Тема: светлая. Тёмная — вне P0.
- Скриншоты каркаса: сняты (FE-0, mock-режим) → `frontend/docs/screens/1440.png`, `390.png`.
- Отличия от прежнего эскиза: прежний эскиз не используется.

- Изменения (FE-0): токены §2.2 перенесены дословно, новых значений нет. Добавлены только псевдонимы shadcn/ui (`--background`, `--foreground`, `--card`, `--popover`, `--primary`, `--secondary`, `--muted`, `--accent`, `--destructive` + `-foreground`, `--ring`, `--input`), каждый ссылается на существующий токен из §2.2.

Действуют без изменений (design-brief §4, corrections §5): null → «Нет данных»; observed/imputed/missing — три стиля; фон только при наличии; цвет полигона = период результата; frontend не вычисляет анализ.

### 8.2. Нерешённые детали (чек-лист вопросов к команде)
| Вопрос | Владелец | Fallback в UI сейчас | Статус |
|---|---|---|---|
| Формат ошибок (RFC 7807 или иной) | B3 | универсальный `AppError` | открыт |
| Откуда брать лимиты площади/вершин/периода | B3 | числовая валидация отключена, показывается текст 422 | открыт |
| Как читать series/events одной `result_version` | B3 | параметр `version`, bundle собирается при совпадении версий | открыт |
| Тело ответов 202 и 429 | B3 | ожидаем `{job_id}`; при 429 — сообщение и ручной повтор | открыт |
| Ключи стадий задачи | B4 | неизвестный ключ → «Анализ выполняется» | открыт |
| SPA-fallback у Go | B4 | один маршрут `/` | открыт |
| Значения `severity` и русские подписи | ML | строка показывается как есть | открыт |
| Форма `deviation` (единица, база) и текст `criteria` | ML | при отсутствии — строка скрыта | открыт |
| Семантика `date` (UTC/интервал), `quality`, агрегация погоды, `spatialNote` | B1 | текст из данных как есть; при отсутствии — скрыто | открыт |
